## 2. 体験上の問題

### 2.1 初めての1打が途中で打ち切られる

- インパクトの画面(6枚目)は、球が飛び始めた時点(`Phase::Executing`)で完了になります。チェックマークを0.65秒出したあと、次の地形カードへ進む際に `ResetPracticeShot` が球をティーへ戻します。
- つまり、**プレイヤーが初めて打った球は、飛び始めて約0.65秒で消えます**。着地も、転がりも、判定の結果もわかりません。
- ゴルフゲームでいちばん気持ちのいい瞬間を、チュートリアルが自分で切っています。「うまく打てたのか」もわからないので、次の実戦ショット(22枚目)まで手応えが残りません。

### 2.2 推奨クラブを外させてから打たせている

- 3枚目で照準ピンを置くと、ゲームがその距離に合うクラブを自動で選びます。
- 4枚目はその直後に「Q/E で別のクラブにする」ことを完了条件にしています。
- 結果として、5〜6枚目の初ショットは **わざわざ合わないクラブに持ち替えた状態** で打つことになります。「ピンを置けばクラブは自動で合う」という便利さを教えた直後に、それを崩させています。

### 2.3 地形と旗の説明中、カメラが説明対象を映していない可能性(要実機確認)

- 地形カード・旗カードでは `UpdateEventCamera` がカメラを説明対象の上空へ動かします。
- しかしこの2つの画面では `GetInputPolicy` がカメラ・ショットとも「許可」を返すため、同じフレームの後半で `CameraController::Update` が呼ばれ、カメラを球の後ろの位置に書き直しているように読めます([WikiGolfSceneUpdate.cpp:553](../src/game/scenes/WikiGolfSceneUpdate.cpp))。
- ヘッダーには「イベントカメラ説明中は入力をロックする」とコメントがあり、`m_inputLocked` という変数も残っていますが、`IsInputLocked` は最初と最後の画面でしか true になりません。入力許可を「段階以上なら許可」の比較に書き換えたときに、説明画面のロックが外れたように見えます。
- もし上書きされているなら、「バンカーは…」と説明している間、画面は球の後ろから動かず、バンカーは映っていません。あわせて、説明中にクリックするとショットが始まり、中クリックでピンも置けます。

### 2.4 終わり方がちぐはぐ

- ゴール後の文言は「タイトル画面へ戻ります…」ですが、実際は接続確認のあと **そのままランダムな本番コースが始まります**(直後の画面では「接続確認後、ゲームを開始します…」に変わります)。
- タイトルからチュートリアルを見直しただけの人も、本番ラウンドへ送られます。
- 23枚目は Enter が「終了」です。それまで Enter は「次へ」だったので、22枚目を飛ばそうとして2回押すと、ゴールに入れないままチュートリアルが終わります。この場合、実績「チュートリアル修了」は付きません。
- 22枚目を Enter で飛ばすと記事の移動が起きないので、「リンクを渡る」体験そのものを飛ばせてしまいます。

### 2.5 途中でやめられない

- チュートリアル中は Esc のポーズが無効です(`!m_isTutorial` の条件)。タイトルへ戻る手段がなく、設定も開けません。
- 全部を飛ばすには Enter を最短でも16回押す必要があり、そのうち8回はチェックマークの0.65秒待ちが入ります。
- 体験版はチュートリアルからしか始められないので、2回目以降に遊ぶ人は毎回これを通ります。

### 2.6 チュートリアルと本番の落差

- チュートリアルのコースは 96×144 の固定地形にカップ6個です。本番の最初のコースは完全ランダムで、カップは最大256個、風もあります。
- チュートリアルで触れないまま本番で必要になるものがあります。

| 本番で必要 | チュートリアルでの扱い |
|---|---|
| ゲージ上のピン印で強さを止める | 「強さの目安が出ます」の一言だけ。ここが狙った距離を打つ唯一の方法 |
| 判定(Special/Great/Nice/Miss)の意味と結果 | 説明なし。Nice で10%飛距離減+約6°曲がることは伝わらない |
| 風 | 説明なし |
| OB の罰打 | カードで読むだけ |
| 前の記事へ戻る(Backspace)、ポーズ(Esc) | 説明なし。チュートリアル中は無効 |
| パターと傾斜表示 | 説明なし(22枚目で自動的にパターになるだけ) |
| 経路を選ぶという目的 | 旗カード3枚で色の意味を読むだけ。選ぶ場面はない |

- 逆に、本番で最初はいらないものを厚く教えています。旗の色6種類の内訳(「白は3〜5手、灰は6手以上、青は未解析」)、マップの操作7種類、地形5種類の性質などです。

### 2.7 間違えたときに何も言わない

- 22枚目で「フェアウェイ」以外のカップに入ると、球は黙ってティーへ戻されます([WikiGolfScene.cpp:115](../src/game/scenes/WikiGolfScene.cpp))。理由の表示はログだけです。
- 何秒も操作がないとき、何度も失敗したときの助け舟がありません。たとえばカメラの画面は「回転とズームの両方」が条件ですが、片方だけやって止まっている人に追加のヒントは出ません。

## 3. UI の問題

### 3.1 パネルの構成

パネルは画面上部中央の 660×172(基準解像度 1280×720)で、中身は次の3段です。

| 要素 | 文字サイズ | 位置(y) | 内容 |
|---|---|---|---|
| 本文 | 20 | 42〜 | 1行目が見出し+段数、2行目以降が説明 |
| 操作チップ | 15 | 108〜142 | いま行う操作 |
| ヒント | 13 | 150〜 | スキップなど |

- **見出しと説明が同じ文字サイズ・同じ色** の1つのテキストです。どこが題でどこが説明か、ひと目で区別できません。
- **本文が3行になると操作チップに重なる可能性があります(要実機確認)**。本文の幅は604で、20ptの全角文字ならおよそ30字で折り返します。説明文が30字を超える画面(照準ピン、地形カードの大半、旗カード、マップの大半)は見出し1行+説明2行の3行になり、行の高さを27前後とすると y=123 付近まで届きます。操作チップは y=108 から始まります。
- **いちばん大事な「いま何をするか」が15ptで、説明より小さい**。プレイヤーが探すのは説明文ではなく操作です。
- ヒントの13ptは、フルHDのモニターでも読みにくい大きさです。

### 3.2 進み具合が伝わらない

- 「8 / 9」が7画面続くので、あと少しのはずが終わらないように感じます。
- 進行バーや点の並びがなく、全体の長さがわかりません。

### 3.3 Enter の役割が画面ごとに違う

| 画面 | Enter の意味 |
|---|---|
| 1 | はじめる |
| 2〜4 | この画面をスキップ |
| 5〜6 | ショット練習を丸ごとスキップ |
| 7〜14 | 次のカードへ(唯一の進行手段) |
| 15〜21 | マップ説明を丸ごとスキップ |
| 22 | スキップして次へ |
| 23 | チュートリアル終了 |

同じキーが「読んだので次へ」と「やらずに飛ばす」を兼ねています。カードを Enter で送る癖がついたまま操作の画面に入ると、練習を飛ばしてしまいます。

### 3.4 画面のどこを見ればいいか示していない

- 「ミニマップに照準ピンを置く」と言いながら、ミニマップを光らせたり矢印で指したりしていません。ミニマップはこの画面で初めて現れます。
- クラブの画面でも、クラブ一覧の強調はありません。
- 操作は `[ 左クリック ]` のような文字の括弧書きです。マウスの絵やキーの形のアイコンのほうが、読まずに伝わります。
- 画面下の操作一覧(`GameplayControlsPanel`)はチュートリアル中は隠してあります。これは良い判断です。

### 3.5 達成の合図が弱い

- 操作で画面を完了したとき、出るのはチェックマークの画像だけで、音が鳴りません(`TriggerStepClear` に効果音の呼び出しがない)。Enter を押したときは打球音(`se_shot_soft.mp3`)が鳴ります。
- つまり「飛ばしたときは音がして、できたときは無音」です。逆であるべきです。
- チェックマークはパネル中央(本文の上)に最大84pxで重なります。

### 3.6 文言

- 「マウスドラッグ」はどのボタンか書いていません(左右どちらでも回ります)。左クリックは打つ操作でもあるので、「左ドラッグで回す/動かさずクリックで打つ」の区別を最初に言うべきです。
- 15〜18枚目のマップ照準の説明に「(設置後にショット画面へ戻ります)」とありますが、チュートリアル中は自動で閉じません([WikiGolfSceneUpdate.cpp:413](../src/game/scenes/WikiGolfSceneUpdate.cpp) の `!m_isTutorial`)。書いてあることと起きることが違います。
- 専門語がそのまま出ます: 「番手」「OB」「未解析」「1 hop」「手」。距離の数え方が「手」「hop」「リンク距離」で揺れています。
- 地形名が `Fairway (フェアウェイ)` と英語が先です。ほかの画面は日本語なので、日本語だけで足ります。
- 19枚目は Space・F・? の3つのキーを1文で紹介し、練習するのは ? だけです。

## 4. 改善案

方針は3つです。

1. **最初の60秒でカップインと記事の移動まで体験させる**。
2. **読ませるより、やらせる**。説明カードは本番で必要になった瞬間に出す。
3. **終わったあと、やさしい本番コースへつなぐ**。

### 4.1 新しい流れ(3記事・操作13回前後)

現在の固定コース(「チュートリアル」「フェアウェイ」の2記事)を3記事に増やし、記事ごとに1つの主題を教えます。

**記事1「チュートリアル」: 打って、入れて、移動する(目標60秒)**

| 手順 | 表示 | 完了条件 | ねらい |
|---|---|---|---|
| 1-1 | 「旗はリンクです。入れると、その記事へ進みます」+ 4m先の旗にカメラが寄る | 2秒で自動、またはクリック | 読むのは1文だけ |
| 1-2 | 「左クリックでスイング開始」 | ゲージが動き出す | 向き・クラブ・ピンはゲームが済ませておく |
| 1-3 | 「青い印のところでクリック」(ゲージ上のピン印を点滅) | 強さを決める | **ピン印で止める** を最初に覚えさせる |
| 1-4 | 「戻ってくる線が帯に重なったらクリック」 | 打つ | |
| 1-5 | 球が止まるまで見せる。入れば記事移動、外れたら「もう一度」 | カップイン | 初ショットを最後まで見せる |

- 最初はゲージ速度を今より遅く(強さ0.5、インパクト0.7)、判定幅を2倍にします。3回外したら吸い込み(`GolfHole::gravity` が既にあります)を弱く効かせて必ず入るようにします。
- カメラ操作はここでは教えません。向きが合っているので不要です。

**記事2「フェアウェイ」: 自分で狙う**

| 手順 | 表示 | 完了条件 |
|---|---|---|
| 2-1 | 「左ドラッグで見回す」 | 回転のみ(ズームは条件にしない) |
| 2-2 | 「狙う場所を中クリック(または T キー)」+ グリーンを光らせる | ピンを置く |
| 2-3 | 「クラブは自動で選ばれました。Q/E で変えられます」 | 表示のみ。2秒で次へ(持ち替えは求めない) |
| 2-4 | 打つ | 球が止まる |
| 2-5 | 判定に応じた一言: 「Nice: 少し手前で、右へ曲がりました」「Great: 狙いどおり」 | 2秒で自動 |
| 2-6 | グリーンに乗ったら「パターに替わりました。地面の矢印が傾きです」 | カップイン |

- 途中にバンカーを1つ置き、入った人にだけ「バンカー: 転がりません。サンドウェッジ向き」を出します。入らなかった人には出しません。

**記事3「グリーン」: 道を選ぶ**

| 手順 | 表示 | 完了条件 |
|---|---|---|
| 3-1 | 「ゴールは『ゴール』の記事です。赤い旗が直通、黄色はあと1記事」 | 2秒で自動 |
| 3-2 | 赤い旗は池の向こう(遠くて危ない)、黄色い旗は手前(安全だが1記事遠回り)に置く | どちらかにカップイン |
| 3-3 | 池に落ちた人にだけ「OB: 1打足して打ち直し」 | 自動 |
| 3-4 | 「M で全体マップ」は画面隅の小さな吹き出しで出すだけ(完了条件にしない) | — |
| 3-5 | ゴール | カップイン |

- 黄色を選んだ人は4記事目を1つ挟んでゴールします。どちらを選んでも正解で、「近道は危ない、遠回りは安全」という経路選びを自分の手で体験できます。

**今の内容の行き先**

| 今の画面 | 新しい扱い |
|---|---|
| 地形カード5枚 | 本番で初めてその地形に止まったとき、1回だけ小さなカードを出す |
| 旗カード3枚 | 赤と黄だけ記事3で教える。残りの色はマップの凡例に任せる |
| マップ7枚 | M の吹き出し1つ。パン・ズーム・ヘルプは、マップを初めて開いたときに画面下の操作一覧で見せる |
| カメラ(回転+ズーム) | 回転だけ。ズームは操作一覧に任せる |
| クラブ持ち替え | 表示のみ |

「1回だけ出すカード」は `save/hints_seen.txt` に表示済みの種類を書いて管理します。設定に「ヒントをもう一度表示する」を置きます。

### 4.2 終わり方

- ゴール後は専用の完了画面を出し、**行き先を選ばせます**: 「最初のコースへ」(初期選択)/「タイトルへ」。文言と実際の動きを一致させます。
- 「最初のコースへ」は完全ランダムではなく、**手で選んだやさしい固定コース** にします。条件の目安は、最短2〜3記事、どちらの記事名も誰でも知っている、カップが少なめ、風が弱い、です。3〜5組用意して順に出します。
- ネットワークにつながらないときは、タイトルへ戻して終わりにせず、「接続できませんでした。もう一度試す/タイトルへ」を出します。
- 実績「チュートリアル修了」は今のまま、ゴールに入れたときだけ。

### 4.3 飛ばし方とやめ方

- **Esc のポーズをチュートリアル中も有効** にし、項目を「再開/チュートリアルを終了する/設定」にします。
- Enter は「読むだけの表示を先へ送る」専用にします。操作の手順を飛ばす手段は、ポーズの「チュートリアルを終了する」だけにします。新しい流れでは読むだけの画面がほぼ無いので、Enter の出番自体が減ります。
- 完了済みの人がもう一度入ったときは、最初に「全部やる/操作だけおさらい(記事2から)」を選べるようにします。
- 製品版で、完了フラグが無いまま「はじめから」を押した人には、「先に3分のチュートリアルを遊びますか」を1回だけ尋ねます。いまは何も聞かずに本番が始まります。

### 4.4 パネルの作り直し

基準解像度 1280×720 での案です。

```
┌──────────────────────────────────────────┐
│ ● ● ● ○ ○ ○ ○ ○ ○ ○ ○ ○ ○     記事1 / 3   │  進行の点(手順の数だけ)
│                                          │
│  青い印のところでクリック                 │  操作: 26pt 太字 1行
│  印は、照準ピンまで届く強さです           │  補足: 16pt 1行(最大28字)
│                                          │
│  [マウス左の絵]                    Esc メニュー │
└──────────────────────────────────────────┘
```

- **操作を一番大きく**、補足は1行・28字以内。2行以上になる文は手順を分けます。
- 見出し(「狙いを定める 3/9」のような題)は廃止します。プレイヤーに必要なのは題ではなく、いますることです。
- 位置は画面上部のまま、高さを120程度に縮めます。ショットゲージ・クラブ一覧・ミニマップと重ならないことを、4つの画面比(16:9、16:10、21:9、4:3)で確認します。
- **指し示し**: その手順で使うHUD部品(ゲージのピン印、ミニマップ、クラブ一覧)の周りを、太さ3pxの枠で1.2秒周期に明滅させます。3D空間の対象(旗、グリーン)には、既存の光柱(`pillarEntity`)を強めに出します。
- **キーとマウスは絵で**。左クリック・中クリック・ドラッグの3種類のマウス絵と、Q/E/M/Esc のキー絵があれば足ります。
- **完了の合図**: チェックマークはパネル右端に40pxで出し、本文には重ねません。専用の短い効果音を鳴らします(打球音の流用はやめる)。待ち時間は0.65秒から0.4秒へ。
- **進行の点**: 終わった手順は塗り、いまの手順は少し大きく。全体の長さと現在地が一目でわかります。

### 4.5 失敗と放置への対応

| 状況 | 対応 |
|---|---|
| 8秒間、求めた操作がない | 指し示しの枠を強くし、補足を具体的な文に替える(例: 「マウスの左ボタンを押したまま、左右に動かします」) |
| 違うカップに入った | 「ここは『ラフ』の記事へのリンクです。いまは『フェアウェイ』を狙いましょう」を2秒出してから戻す |
| 同じショットを3回外した | ゲージをさらに遅くし、判定幅を広げる。記事1では吸い込みを有効にする |
| 中クリックができない(10秒たってもピンが置かれない) | 「T キーでも置けます」を出す(T の割り当て追加が前提) |
| OB | その場で「OB: 1打足して打ち直します」を出す。カードで先に読ませない |

### 4.6 文言の規則

- 1手順につき操作は1つ、文は1〜2文。
- 距離の数え方は「あと◯記事」に統一します(「hop」「手」「リンク距離」は使わない)。
- 「番手」→「クラブ」、「未解析」→「調べている途中」、「OB」は初出で「OB(コースの外)」。
- 起きることと書くことを一致させます(4.2 の終了文言、マップ照準の「戻ります」)。
