チュートリアル案内パネルの別案

今のパネルと、作りを変えた5案を同じ画面の上で比べます。上のボタンで場面を切り替えると、案ごとに「操作が2つの場面」「HUDの一部を指す場面」「できた直後」がどう見えるか確かめられます。画面は 1280×720 を縮めた模型で、HUDの位置は大まかです。

今のパネルが「AIっぽく」見える理由
  • 左の色帯つき角丸カード、区切った進行バー、「章名 n / m」、キーの形のチップ、明滅する青い枠、緑のチェック。どれもアプリの初回案内でよく見る部品で、それを全部載せています。
  • ほかのHUDは、Wikipediaの紙面に寄せた落ち着いた作りです(#f8f9fa の面、細いグレー線、リンクの青)。案内だけが別の流儀なので、後から貼った感じがします。
  • 情報が多すぎます。章・ページ・見出し・キー・補足・スキップ案内の6段を毎回読ませています。
  • 余白・角丸・文字サイズがどこも同じ調子で、どこを読めばいいか目が止まりません。

案やめるもの代わりに使うもの今のエンジンでの手間弱点
A 百科事典の注記色帯・角丸・キー形チップ・進行バー・明滅枠Wikipediaの注記の体裁、リンク色、脚注番号 [1]小。UIText の背景・細線・色だけで組める。文中のリンク色は文字を分けて並べるおとなしく、初見で目に入りにくい
B キャディのひと言カード、進行バー、スポットライト枠指したいHUDのそばに出る吹き出し1つ。しっぽで場所を示す中。吹き出しのしっぽに画像が1枚要る。場面ごとに置き場所を決める話し手がいないと浮く。キャラを立てるなら絵が要る
C スコアカード青の進行バー、緑チェック7ホール分のスコアカードと赤い○、はんこ中。はんこと○は画像。紙の色と緑線は UIText で足りるゴルフらしさは強いが、Wikipediaらしさとは別の方向
D 画面に直接書くパネルそのもの影つきの白文字1〜2行、キーだけ小さな白札小。UIText の影が要る(無ければ2枚重ねで代用)背景が明るい場所で読みにくい。説明を長く書けない
E ヤーデージブック整ったカード、明滅枠手書きのメモと、HUDへ伸びる手描きの矢印大。矢印を場面ごとに描いた画像が要る。手書き書体の追加も要る作るのが重い。HUDの位置を変えると矢印も描き直し

おすすめは A を土台に、HUDを指す場面だけ B の吹き出しを足す形です。ほかのHUDと同じ紙面の流儀にそろうので「後から貼った感じ」が消え、手間もいちばん小さく済みます。指したい部品がある場面だけ吹き出しで近くに出せば、明滅する枠も要りません。ゴルフらしさを前に出したいなら C、とにかく画面をすっきりさせたいなら D です。
