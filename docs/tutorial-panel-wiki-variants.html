百科事典風パネルの案

A「百科事典の注記」の方向で、Wikipedia の紙面にある部品をそれぞれ土台にした5案です。上のボタンで場面を切り替えると、案ごとに「キーが2つ」「HUDを指す」「できた直後」がどう見えるか確かめられます。画面は 1280×720 を縮めた模型で、HUD の位置は大まかです。

5案とも同じにすること
  • 色は今の HUD にあるものだけを使います。面 #f8f9fa、線 #a2a9b1、操作 #3366cc、できた操作 #795cb2(訪問済みリンクの紫)、完了の一言 #14866d。
  • 見出しは明朝、本文はメイリオです。明朝は Windows 標準の游明朝を使うので、フォントファイルは増えません。
  • 角丸、影、色帯、明滅、キーの形の部品は使いません。動きは、内容が替わるときの短いフェードだけです。
  • HUD を指すときは、その部品を細い点線で囲み、角に脚注番号 [1] を付けます。本文中の「ミニマップ[1]」と番号で対応させます。

案土台にする部品進み具合の見せ方良いところ弱点
A1 囲み注記記事上部の注記ボックス下端のパンくず「カメラ › ねらう › 打つ」いちばん素直で小さい。前回の案そのままおとなしく、特徴が弱い
A2 インフォボックス記事右の基本情報の表表の最後の行「進み具合 3 / 7 章」キーと動作が表の行になるので、一目で拾える文章が無いので、なぜそうするかは書きにくい
A3 記事の冒頭記事の題と書き出しの一文題の下の小さな一行「チュートリアル 3 / 7」「強さ決め（つよさぎめ）は、…操作である。」と、いちばん Wikipedia らしく、読んで楽しい文が長めで、読む量が増える
A4 目次記事の目次ボックス目次そのもの。済んだ章は紫、いまの章だけ開いて中身を出す進行バーの代わりに、全体のどこにいるかが言葉で分かる縦に長い(章名7行ぶん)。いまの章以外は閉じた表示も用意したい
A5 脚注本文の注と、下の脚注一覧なし(A1 のパンくずを足せる)「中クリック＝ホイールを押しこむ」など、操作に慣れない人向けの説明を本文の邪魔をせずに足せる脚注まで読まない人もいる。部品がやや多い

おすすめは A4「目次」です。前回の「AIっぽさ」の中心だった区切りの進行バーを、Wikipedia の目次に置き換えられます。章の名前、済んだ所、いまの所が一つの部品にまとまり、ほかの HUD とも見た目がそろいます。縦の長さが気になる場合は、いまの章の前後1つだけを見せる形に縮められます。次点は A3 です。題と書き出しの一文に味があって、読んで楽しいのが良いところです。
